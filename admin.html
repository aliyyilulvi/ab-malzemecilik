GitHub Bağlantısı

Bu panel şifreyle değil, GitHub'a bağlanarak çalışır — çünkü site ücretsiz GitHub Pages üzerinde barınıyor ve ayrı bir sunucusu yok. Ürün eklediğinizde değişiklik doğrudan reponuza kaydedilir ve siteye birkaç dakika içinde yansır.

Güvenlik notu: Aşağıya gireceğiniz "erişim anahtarı" (token) reponuza yazma yetkisi verir. Bu sayfanın linkini ve anahtarınızı kimseyle paylaşmayın. Anahtar yalnızca bu tarayıcı sekmesinde tutulur, kapattığınızda silinir.

Anahtar almak için: GitHub'da sağ üstteki profil fotoğrafınıza tıklayın → Settings → en alttaki Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). "repo" kutucuğunu işaretleyip oluşturun, çıkan kodu buraya yapıştırın.
